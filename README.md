# art_generator
The goal of the project is to store all the art pieces from the [Metropolitan Museum of Art's API](https://metmuseum.github.io/), then write a program that generates new art pieces based on given art pieces i.e. from all impressionism art, generate new art. From all art from artist A, generate new art. Things of that nature.

Generations:
Generate based on all male artists, all female artists.
All artists born in a certain year, alive during a range of years
All artwork made during a certain year, all artwork made during a range of years
All artwork based on artist nationality
All artwork based on a type of art i.e. impressionism or a set of types with weights that make the generated work more like one type or another
